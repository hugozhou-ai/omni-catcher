# Note

Write clean Markdown with a concise summary, useful headings, key points, and source links. For primarily English source material, make substantive summaries bilingual with English first and Chinese second. Reuse stable existing tags and keep tags broad and searchable.

For papers and articles, prefer merging into a matching reading note or collection when appropriate. Preserve DOI, arXiv, and source URLs. Do not turn requests to summarize or organize knowledge into todos.
